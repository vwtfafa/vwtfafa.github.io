Privacy Policy

Last updated: September 2026

1. Controller

vwtfafa
Contact: Discord “vwtfafa” or via github.com/vwtfafa

2. General

This website uses no cookies, no trackers, no accounts and no ads. No analytics tools are used. Below is what data is still processed for technical reasons and why.

3. Hosting

This website is served via GitHub Pages (GitHub Inc., USA). When you visit, the host processes technically necessary data such as your IP address (server logs). Legal basis is Art. 6(1)(f) GDPR (secure and stable delivery of the website).

4. Local storage (localStorage)

The following data is stored only locally in your browser and never sent to me:

  • lang – selected language (German/English)
  • theme – selected color scheme (light/dark)
  • modrinthCache-v2, gh-stats-v1, gh-profile-v1, bstatsCache – cached API responses (max. 1 hour) so the page loads faster

You can delete this data at any time via your browser settings.

5. External APIs and content

To show live data, the page queries directly in your browser:

  • Modrinth API (downloads, versions, project icons)
  • bStats (server and player counts)
  • GitHub API (stars, last update)
  • mc-heads.net (Minecraft skin images)

Your IP address is transmitted to these providers, some of which are based in the USA. Legal basis is Art. 6(1)(f) GDPR (operation of the website). The providers' own privacy policies apply additionally.

6. Contact form

The contact form opens a GitHub issue containing the data you entered (name, email, message). Providing it is voluntary; note that the data will be publicly visible there. GitHub's terms apply.

7. External links

Links to Modrinth, GitHub or Discord lead to third-party services. The respective providers are responsible for their content and data processing.

8. Your rights

You have the following rights towards the controller:

  • Access to stored data (Art. 15 GDPR)
  • Rectification of inaccurate data (Art. 16 GDPR)
  • Erasure and restriction of processing (Art. 17, 18 GDPR)
  • Data portability (Art. 20 GDPR)
  • Objection to processing (Art. 21 GDPR)
  • Lodge a complaint with a supervisory authority (Art. 77 GDPR)

Since this website itself stores no personal data, just reach out via Discord or GitHub for any request.
